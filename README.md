# Website – Johanna Isaza Merchan, Psychologische Beratung

Statische Website (HTML/CSS/JS, kein Build nötig). Einfach `index.html` im Browser öffnen.

- `index.html` – Startseite (Hero, Ablauf, Themen, Über mich, Honorar, FAQ, Kontakt)
- `impressum.html`, `datenschutz.html` – Pflichtseiten
- `assets/` – CSS, JS, Bilder und lokal eingebundene Schriften (keine Google-Server → DSGVO)

**Entwurf:** Gelb markierte Stellen (`class="ph"`) sind Platzhalter. Vor dem Livegang ersetzen
und das Entwurfs-Banner (`.draft-banner`) entfernen.

**Rechtlicher Rahmen:** Als *geprüfte Psychologische Beraterin (VFP)* keine Begriffe wie
„Therapie“, „Behandlung“, „Patient“, „Diagnose“ oder „Psychologin“ für das eigene Angebot verwenden
und keine Heilversprechen machen. Der Hinweis „keine Psychotherapie / keine Heilkunde“ muss erhalten bleiben.
